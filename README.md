# MC 百科内容屏蔽

Tampermonkey 用户脚本，可在 MC 百科屏蔽指定的模组、整合包、作者、评论用户和评论正文。支持条目 ID、账号 UID、关键词和正则。

## 安装与更新

安装 Tampermonkey 后，[点击安装或更新脚本](https://raw.githubusercontent.com/MX703DR/mcmod-filter/main/mcmod-filter.user.js)。如果此前是手动粘贴安装的旧版，可先用此链接覆盖安装一次，后续更新由 Tampermonkey 从本仓库检查。

## 使用

- 点击网页右下角的盾牌打开设置。规则修改即时生效，可导入或导出 JSON。
- 在条目卡片或评论上按 Shift + 右键打开屏蔽菜单。
- 主评论命中黑名单时隐藏整楼。楼中楼评论命中时，确认回复关系的后续评论也会隐藏。百科只提供被回复者的 UID；同一账号有多条可能的目标评论时，无法确定归属的回复会保留。
- 在「基础」打开审查模式，可查看命中内容和原因，并将误伤对象加入白名单。关闭后恢复正常屏蔽。

规则和设置保存在浏览器的脚本存储中。启用作者精确过滤时，脚本会读取 MC 百科公开条目页。
